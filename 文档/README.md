# 文档目录

> 项目：融合 RAG 与提示工程的 AI 生成内容隐性广告识别测试方案研究

---

## 目录结构

```
文档/
├── README.md                ← 本文件
│
├── 01-项目规划/              ← 设计方案、路线图、计划
│   ├── 毕设详细设计文档.md
│   └── 学习与开发路线图.md
│
├── 02-技术调研/              ← 技术选型分析、风险审查
│   └── 设计风险审查与简化方案.md
│
├── 03-会议与沟通/            ← 导师会议记录、沟通备忘
│   └── (待创建)
│
├── 04-知识库资料/            ← 广告法规原文、案例资料、品牌数据
│   └── (待创建)
│
├── 05-实验数据/              ← 测试集、实验结果CSV、对比图表
│   └── (待创建)
│
├── 06-参考资料/              ← 文献PDF、参考论文、教程链接
│   └── (待创建)
│
├── 07-论文草稿/              ← 各章节草稿、导师批注版
│   └── (待创建)
│
├── 08-答辩准备/              ← PPT、演讲稿、答辩QA
│   └── (待创建)
│
└── 开发与学习日志/           ← 每日开发记录
    └── 开发日志.md
```

## 使用规则

1. **新增文档**按照内容和时间放入对应文件夹
2. **命名规范**：`日期-内容描述.md`（如：`2026-08-03-导师第一次沟通记录.md`）
3. **每完成一个 Phase**，更新 `开发日志.md`
