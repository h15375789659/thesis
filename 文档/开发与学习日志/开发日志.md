### 2026-09-14 | Phase 0：环境搭建

- **用时**：约 1 小时
- **做了什么**：
  - 确认 Python 3.13.14 环境
  - 创建虚拟环境 `code/venv`
  - 安装全部依赖并验证导入
  - 更新 `requirements.txt` 为实际安装版本
- **遇到的问题**：
  1. **scikit-learn==1.5.0 编译失败**：该版本无 Python 3.13 的预编译 wheel，Windows 上从源码编译报错（ninja 路径问题）
  2. **pandas==2.2.0 无 cp313 wheel**：版本太旧，同样无 Python 3.13 支持
  3. **chromadb==0.5.5 与 numpy 2.x 冲突**：旧版 chromadb 要求 `numpy<2.0`，但 scikit-learn 1.9+ 要求 numpy 2.x
- **解决方法**：
  - scikit-learn: 1.5.0 → **1.9.0**（支持 cp313 wheel）
  - pandas: 2.2.0 → **2.3.3**（被 streamlit 自动拉入）
  - chromadb: 0.5.5 → **1.5.9**（支持 numpy 2.x）
  - 最终所有包均安装成功，导入验证通过
- **产出物**：`code/venv/` + `code/requirements.txt`（更新为实际版本）

### 2026-09-17 | Phase 5：Prompt 变体对比测试完成

- **用时**：约 1 小时（含小测试集构建 + 标注 + 跑测试）
- **做了什么**：
  - 构建小测试集 `test_set.json`（10 条小红书真实文本，标注 4 广告 + 6 非广告）
  - 写对比测试脚本 `compare_prompts.py`
  - 跑完 8 个 mode × 10 条 = 80 次 LLM 调用
- **测试结果**（准确率，样本仅 10 条，仅供方向参考）：
  - simple 90%、cot 90%、pe 90%、full 90%、full_templates 90%
  - rag_only 80%、role 80%、fewshot 80%
- **关键发现**：
  1. **is_ad 判定上，裸 LLM 与完整方案无差异（90% vs 90%）**——印证「判断是否广告纯 LLM 够用，RAG 增益有限」的预判（答辩 Q6）
  2. **rag_only（仅 RAG 无提示工程）反而最差**——说明 RAG 需配合提示工程才能发挥价值
  3. **test_001（翻包 EDC）全军覆没**——8 个 mode 都判「广告」，人工标「非广告」，暴露「品牌露出 vs 隐性广告」的边界争议
- **遇到的问题**：无

- **产出物**：`test_set.json` + `compare_prompts.py` + 对比测试结果
- **待办**：① 讨论 test_001 标注分歧；② Phase 9 测试集扩到 100+ 条后正式评估（风险分级/法条引用维度才能真正体现 RAG 价值）
